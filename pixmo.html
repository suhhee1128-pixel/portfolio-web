Unveiling PIX.MO:
Where AI-Generated Sprites
Finally Work in Games

PIX.MO is a solo AI project where I explored whether custom AI-generated sprites could go beyond visuals and become truly playable game assets.

Instead of stopping at image generation, I challenged myself to design an end-to-end system—from character creation, to consistent sprite generation, to real in-game validation inside a playable PIX.MO game.

Visit Website

Problem Definition

1. Customization
Creators want to define Character style, Color palette, Mood, weapon, role. But most generators produce generic outputs.

2. Consistency Across Frames
Sprites must share the same scale, pivot, and proportions and maintain visual continuity across actions (idle, attack, skill, etc.). Without this, animation breaks.

3. Playability Validation
Even visually consistent sprites often don’t align with hitboxes, break combat timing, or feel “off” during gameplay. True validation only happens inside a real game.

Solution

I designed PIX.MO as a three-layer system, not a single feature.

1. Customized Character Generation

Users define characters through structured inputs (Name & description, Color & mood, Weapon type). This ensures generation starts with intent, not randomness.

2. Consistent Sprite System

Instead of generating single images, I designed the system around action-based sprite sets with fixed frame counts per action and shared canvas/scale/pivot. Each action (Idle, Attack, Skill, Dash, Death) produces a coherent sprite sequence.

3. Playable Verification Inside a Game

To avoid "theoretical usability," I embedded sprites into a real 'PIX.MO' game. I built a simple combat system with HP, damage, and hit detection, allowing real-time sprite swapping.

This allowed me to verify animation flow, combat readability, and visual feedback during hits.

Process & Effort

This project required bridging AI generation → engine constraints → gameplay reality.

What I did end-to-end:

  • Designed sprite constraints suitable for games
  • Experimented with AI generation tools and prompts
  • Iterated sprite sets based on engine feedback
  • Integrated sprites into a playable game loop
  • Debugged animation and collision issues
